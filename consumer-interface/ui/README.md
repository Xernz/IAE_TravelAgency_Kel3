# Travel Agency Consumer Interface UI

This is a simple React front-end for the Travel Agency System, using MUI (Material-UI) for a modern look and feel.

## Features
- Book, update, delete, and view bookings for flights and hotels
- Browse available flights and hotels
- Clean, responsive UI using Material-UI

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure
- `src/App.js`: Main app with tab navigation
- `src/components/BookingManager.js`: Manage bookings
- `src/components/FlightBrowser.js`: Browse flights
- `src/components/HotelBrowser.js`: Browse hotels

---

This UI expects the consumer backend interface to be running on `http://localhost:4000` by default.
